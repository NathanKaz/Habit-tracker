# Трекер привычек

Настольный трекер привычек с календарём, сериями и доступом с телефона по локальной сети.

[English](README.md) · **Русский**

## Возможности

- Два типа привычек: «да/нет» и счётчики с целью на день (например, 8 стаканов воды).
- Гибкие расписания: каждый день, выбранные дни недели или N раз в неделю.
- Серии: текущая и лучшая, а также прогресс за неделю, месяц и всё время.
- Отдельная для каждой привычки опция «сбрасывать серию при пропуске».
- Экран «Сегодня» и календарь на месяц, чтобы заполнить пропущенные дни.
- Доступ с телефона или другого компьютера в той же сети (подключение по QR-коду).
- Интерфейс на английском и русском или вслед за системным языком.
- Светлая, тёмная и системная темы; неделя может начинаться с понедельника или воскресенья.
- Значок в системном трее, автозапуск и экспорт/импорт JSON для резервных копий.

## Стек

Electron 44 · React 19 · Vite 8 · Express 5 · WebSocket (`ws`) · Zod 4 · TypeScript. Тесты — на Vitest.

## Требования

- Node.js 20+ (рекомендуется 22 LTS) и npm.
- Для локальной сборки установщиков: Linux или macOS; сборка под Windows из Linux требует Wine.

## Разработка

```bash
npm install
npm run dev        # Vite на :5173, API на :47821, окно Electron
npm run typecheck  # проверка типов main и renderer
npm test           # Vitest
npm run build      # сборка main-процесса и renderer
```

## Сборка пакетов

```bash
npm run package       # Linux: AppImage + .deb
npm run package:win   # Windows: установщик NSIS + portable .exe
npm run package:mac   # macOS: .dmg + .zip (только на macOS)
npm run package:all   # всё перечисленное
```

Готовые файлы попадают в `release/`.

## Загрузка

Свежие сборки — на странице [Releases](https://github.com/NathanKaz/Habit-tracker/releases):

- **Linux** — `habit-tracker-<версия>-x86_64.AppImage` (`chmod +x` и запустить) или `habit-tracker-<версия>-amd64.deb`.
- **Windows** — `habit-tracker-<версия>-setup.exe` (установщик) или `...-portable.exe`.
- **macOS** — `habit-tracker-<версия>-<арх>.dmg` или `.zip` (Intel `x64`, Apple Silicon `arm64`).

Сборки пока не подписаны, поэтому Windows SmartScreen и macOS Gatekeeper могут показать предупреждение. На macOS при первом запуске откройте приложение через «ПКМ → Открыть». Поставляются только 64-битные сборки.

## Доступ с телефона

1. Откройте **Настройки** и включите **Доступ по сети**.
2. Подключите телефон к той же сети Wi-Fi.
3. Отсканируйте QR-код или откройте показанный адрес `http://<local-ip>:47821` в браузере телефона.
4. Войдите под учётной записью, созданной на компьютере.

По умолчанию сервер слушает `127.0.0.1:47821` и открывается для локальной сети только при включённом доступе по сети. Создать учётную запись можно только с самого компьютера.

## Данные и резервные копии

Все данные лежат в одном JSON-файле в каталоге `userData` приложения Electron:

| ОС | Путь |
|----|------|
| Linux | `~/.config/Habit Tracker/data.json` |
| macOS | `~/Library/Application Support/Habit Tracker/data.json` |
| Windows | `%APPDATA%\Habit Tracker\data.json` |

Для резервных копий используйте **Настройки → Экспорт / Импорт**. Пароли хранятся как соль + хеш [scrypt](https://nodejs.org/api/crypto.html#cryptoscryptpassword-salt-keylen-options-callback), а токены сессий — только в виде SHA-256-хешей.

## Структура проекта

```
src/
  main/       главный процесс Electron: окно, трей, HTTP-сервер, хранилище, доменная логика
    api/      маршруты Express, схемы валидации, сборка состояния
    domain/   расписания, серии, даты, типы
  renderer/   интерфейс на React (экраны, компоненты, состояние, i18n)
  shared/     код, общий для main и renderer
  i18n/       серверные переводы
tests/        модульные тесты Vitest
scripts/      генерация иконок
```
